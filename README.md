# Projects Portfolio
A collection of hands-on data analytics and machine learning projects built with Python, Pandas, Matplotlib, Seaborn and other related data tools. developed as part of my learning in Microsoft Fabric and Azure. This portfolio showcases my skills in data exploration, cleaning, transformation, visualisation and analysis using real-world datasets. Each project is documented in a notebook so the full workflow can be followed step by step.

## Projects
#### $\color{#000080}{\textbf{1. Exploratory Data Analysis (EDA) with Sales Dataset}}$
Performed EDA on online retail transaction data using Python. Imported data from Excel, then cleaned, merged and transformed three related tables (Sales, Invoice and Product) with Pandas. Created Matplotlib and Seaborn visualisations to identify trends, outliers, distributions and correlations.

- **Tables:** Sales, Invoice, Product

#### $\color{#000080}{\textbf{2. Exploring and Analyzing Employee Dataset}}$
Explored and analysed an employee dataset using Python to uncover patterns in workforce data.
